# 💌 Carta de Desculpas e Amor

Uma página web interativa e romântica criada com muito amor, para expressar pedidos de desculpas, saudade e afeto profundo. Inclui slides com fotos pessoais, animações suaves, corações flutuando, efeitos especiais e uma música de fundo para tornar o momento ainda mais tocante.

## ✨ Funcionalidades
- **Slides interativos**: Navegue por 8 slides (intro + 7 com fotos e frases românticas).
- **Animações românticas**: Carta animada com zoom, corações flutuando, "gotas" de amor ao interagir com botões.
- **Música de fundo**: Vídeo em loop do YouTube (PARTYNEXTDOOR - No Chill) para um tom suave e emocional.
- **Design pixel rosa**: Estilo retrô com gradientes rosa, fonte pixelada e efeitos visuais.
- **Responsivo**: Funciona em desktop e mobile.

## 🚀 Como Usar
1. **Hospede online**: Faça upload da pasta inteira para GitHub Pages, Netlify ou similar (veja instruções abaixo).
2. **Acesse o link**: Compartilhe o link gerado com sua namorada. Ela verá a carta completa ao clicar.
3. **Navegação**: Use os botões "Próximo" e "Anterior" para avançar nos slides. Passe o mouse nos botões para efeitos especiais.
4. **Música**: Permita autoplay no navegador para ouvir a música em loop.

### Hospedagem Rápida (GitHub Pages)
1. Crie um repositório no [GitHub](https://github.com).
2. Faça upload dos arquivos (HTML, imagens na pasta `IMG/`).
3. Ative Pages em Settings > Pages (selecione branch main).
4. O link será algo como: `https://seu-usuario.github.io/carta-desculpas/`.

### Teste Local
- Abra `carta_desculpas.html` no navegador (ou use "Live Server" no VSCode).
- Certifique-se de que as imagens estão na pasta `IMG/` e o vídeo do YouTube carrega.
